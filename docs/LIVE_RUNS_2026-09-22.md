# Live runs, 22 and 23 September 2026

Real app (Vite dev server on the owner's Mac), real registries, `scripts/live-e2e.mjs` clicking what an investigator would click. The model endpoint was a stand-in: Claude subagents answering the xAI-compatible `/v1/chat/completions` request, because no xAI key was available. Every request and reply is kept on the Mac (`meridian-intake-20260922/live/standin*`); reports and screenshots are in `live/runs*`. No record text from those runs is committed here (publisher abstracts).

Plans: `scenarios/live/`. A = IV ketamine for refractory neuropathic pain (seed); B = colorectal ERAS unplanned extra night (seed); C = overnight PCA programming errors around handover (seed); D = point-of-care gastric ultrasound in patients on GLP-1 receptor agonists, diagnostic accuracy (fresh, written after the code was frozen for the run).

## Limits of these runs

- The model was a stand-in, not Grok 4.5; appraisal answers took 5 to 40 minutes each and three stand-in agents crashed, so most studies ran on partial appraisal. The app's handling of those failures ("Earlier batches stay applied", visible reason) is part of what was observed.
- One run per study; no blinded rating of scientific quality.
